# Infinite Experiment

Infinite Experiment connects **Infinite Flight** live multiplayer, your virtual airline’s
records (often Airtable), and your **Discord** community. Comrade Bot is the Discord
surface; **Politburo** is the backend that owns identity, membership, configuration, and
shared JSON APIs.

## Who this site is for

- **Pilots** registering with Comrade Bot and joining a VA on Discord
- **VA staff and administrators** understanding roles, Discord linkage, and the web portal
- **Integrators** reading the [Politburo API reference](api/reference/index.html)

## Get started

1. [Register your account](guides/registration.md) with `/register` in Discord.
2. If you run a VA, read [Roles & your VA](guides/roles-and-va.md) before `/initserver`.
3. See [Features](features.md) for what is available today and what is coming next.

## API documentation

Browse the interactive [API reference](api/reference/index.html) (ReDoc, self-hosted on this
site). Machine-readable OpenAPI is at
[openapi.yaml](api/reference/openapi.yaml) after each deploy.
